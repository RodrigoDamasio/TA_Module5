# TA_Module5 — Production

Module 5 of the Taller Academy course on LLMs and agents: production patterns for AI systems (rate limiting, caching, fallbacks), prompt-injection defenses, cost optimization, event-driven integration, responsible AI, and multi-platform deployment.

## Lab 5 — Multi-Agent Research Assistant

A **Supervisor** agent coordinates **Researcher** (Wikipedia), **Writer**, **Reviewer** and **Fact-Checker** workers through the `DELEGATE` / `TASK` / `FINAL` protocol, and answers a research task with cited sources. Extensions: parallel workers, human approval, memory, more workers.
